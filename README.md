
# 🎓 AcadEase
### Smart Student Productivity and Attendance Management System

**Make Academics Easier.**

AcadEase is a student productivity web application designed to help students manage their academic life in one place. It combines attendance tracking, timetable management, task planning, focused study sessions, and study analytics in a simple and user-friendly interface.

## ✨ Features

- 📊 **Dashboard** — View an overview of your academic activities.
- 📅 **Weekly Timetable** — Create and manage your weekly class schedule.
- ✅ **Attendance Management** — Record attendance for individual classes and track attendance statistics.
- 📝 **Task Management** — Organize academic tasks and keep track of pending work.
- 🍅 **Pomodoro Timer** — Use focused study sessions and breaks to improve productivity.
- ⏱️ **Study-Time Tracking** — Record study sessions and monitor your progress.
- 🎯 **Daily Study Goals** — Set a daily study-time target and track your progress.
- 📈 **Study Analytics** — Visualize study habits through charts and statistics.
- 💾 **Local Data Storage** — Save application data in the browser using LocalStorage.

## 🛠️ Technology Stack

- **HTML5** — Application structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Application logic and interactivity
- **LocalStorage** — Browser-based data persistence
- **Chart.js** — Data visualization, if included in the project

## 💡 Problem Statement

Students often manage their class schedules, attendance, assignments, and study plans across different tools. This can make it difficult to maintain consistent study habits and stay aware of academic progress.

AcadEase aims to bring these essential productivity features together in a single, accessible web application.

## 🎯 Project Objectives

- Simplify student timetable and attendance management.
- Encourage consistent study habits through focus sessions and daily goals.
- Help students organize tasks and academic responsibilities.
- Provide visual insights into study patterns and progress.
- Offer a simple interface without requiring a backend setup.

## 🔮 Future Scope

- Assignment and examination deadline reminders.
- Attendance shortage prediction based on configurable attendance requirements.
- Data export and backup/restore functionality.
- Cloud synchronization across multiple devices.
- Optional secure login and personalized student profiles.

## ⚠️ Limitations

AcadEase currently uses browser LocalStorage, so data is generally limited to the browser and device where it was entered. Clearing browser data may remove saved information. Cloud synchronization and backend-based authentication are not currently included.
